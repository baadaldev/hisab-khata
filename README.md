## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

### ১. দৈনিক আয় ও ব্যয়ের হিসাব (Daily Expense & Income Tracking)
- **সহজ এন্ট্রি:** এক ক্লিকে খরচ (Expense) ও আয় (Income) এন্ট্রি করার সুবিধা।
- **বিভিন্ন খাত (Categories):** খাবার, মেস/বাড়ি ভাড়া, বাজার, যাতায়াত, বিল, কেনাকাটা, চিকিৎসা, বেতন, ফ্রিল্যান্সিং ইত্যাদি সুন্দর আইকন ও কালার ট্যাগসহ।
- **পেমেন্ট মাধ্যম:** ক্যাশ (Cash), বিকাশ (bKash), নগদ (Nagad), রকেট, ব্যাংক ও কার্ড সিলেক্ট করার অপশন।
- **ফিল্টারিং ও সার্চ:** মাস অনুযায়ী ফিল্টার, নির্দিষ্ট খাত অনুযায়ী ফিল্টার ও যেকোনো নোট দিয়ে দ্রুত সার্চ।

### ২. ধার-দেনার বিস্তারিত হিসাব (Debts & Loans / দেনা-পাওনা)
- **আমি পাবো (Receivable):** কার কাছে কত টাকা পাওনা, মোবাইল নম্বর ও পরিশোধের শেষ তারিখ।
- **আমি দেবো (Payable):** কে কত টাকা পাবে বা কাকে কত দিতে হবে।
- **আংশিক জমা / কিস্তি (Partial Payments):** কেউ কিস্তিতে বা আংশিক টাকা পরিশোধ করলে স্বয়ংক্রিয়ভাবে অবশিষ্ট টাকার হিসাব রাখা ও হিস্ট্রি লগ।
- **কনফেটি উদযাপন:** সম্পূর্ণ টাকা পরিশোধ হলে কনফেটি অ্যানিমেশন ও "পরিশোধিত" স্ট্যাটাস।
- **১-ক্লিক হোয়াটসঅ্যাপ রিমাইন্ডার:** সরাসরি এক ক্লিকে মার্জিত ভাষায় হোয়াটসঅ্যাপ রিমাইন্ডার মেসেজ পাঠানোর বাটন!

### ৩. মাসের হিসাব ও অ্যানালিটিক্স (Monthly Analytics & Comparisons)
- **মাসের তুলনা (Month-over-Month Comparison):** বিগত ৬ মাসের খরচের ভিজ্যুয়াল গ্রাফ—কোন মাসে খরচ বেশি আর কোন মাসে কম হয়েছে তা সহজে দেখার উপায়।
- **খাত অনুযায়ী খরচ (Category Breakdown):** নির্বাচিত মাসে কোন খাতে কত শতাংশ (%) এবং কত টাকা খরচ হয়েছে তার প্রগ্রেস বার।
- **স্মার্ট ইনসাইট:** গত মাসের তুলনায় কত শতাংশ খরচ বাড়ল বা কমল তার রিয়েল-টাইম নোটিশ।

### ৪. ১০০% অফলাইন ও নিরাপদ ডাটা (Offline & Local Storage)
- আপনার ডাটা আপনার ফোনের ব্রাউজারেই সম্পূর্ণ নিরাপদে সংরক্ষিত থাকে (`localStorage`)।
- কোনো ক্লাউড সার্ভারে ডাটা যায় না, ফলে আপনার গোপনীয়তা সুরক্ষিত।
- **JSON ব্যাকআপ ও রিস্টোর:** এক ক্লিকে পুরো ব্যাকআপ ফাইল ডাউনলোড এবং যেকোনো ডিভাইসে আপলোড করে রিস্টোর করার সুবিধা।
- **Excel / CSV এক্সপোর্ট:** এক্সেল বা গুগল শীটে দেখার জন্য সিএসভি ফাইল ডাউনলোড।

### ৫. প্রগ্রেসিভ ওয়েব অ্যাপ (PWA / Mobile App Experience)
- যেকোনো স্মার্টফোনে (Android / iPhone) ব্রাউজার থেকে **"Add to Home Screen"** করলেই এটি সম্পূর্ণ আসল অ্যাপের মতো কাজ করবে।

## 📲 কীভাবে ফোনে অ্যাপ হিসেবে ব্যবহার করবেন? (How to Install on Phone)

1. আপনার ফোনের **Chrome** বা **Safari** ব্রাউজারে লিংকটি খুলুন:  
   👉 **[https://baadaldev.github.io/hisab-khata/](https://baadaldev.github.io/hisab-khata/)**
2. ব্রাউজারের ওপরের ডানপাশের **৩-ডট মেনু (⋮)** অথবা নিচে থাকা **Share বাটন** চাপুন।
3. **"Add to Home screen"** (হোম স্ক্রিনে যোগ করুন) বা **"Install App"** অপশনটিতে চাপ দিন।
4. ব্যস! আপনার ফোনের হোম স্ক্রিনে **হিসাব খাতা** অ্যাপের আইকন চলে আসবে এবং এটি অফলাইনেও যেকোনো সময় ব্যবহার করতে পারবেন।

## 💻 লোকাল ডেভেলপমেন্ট (Local Development)

```bash
# ক্লোন করুন
git clone https://github.com/baadaldev/hisab-khata.git

# প্রজেক্ট ফোল্ডারে যান
cd hisab-khata

# প্যাকেজ ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
